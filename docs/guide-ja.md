# DESMAN(P): テスト参加者向けガイド

テストへのご協力ありがとうございます。このガイドでは、DESMAN のインストール方法、
試してほしいこと、問題の報告方法を説明します。まずは第 1～3 節を読み、
残りは必要になったときにご覧ください。

## 0. はじめにお読みください

- **これは試作版です。** 突然終了したり、応答しなくなったり、不自然な回答を返したり、
  作業途中の内容が失われたりすることがあります。大切な作業や、やり直せない作業は
  任せないでください。問題を見つけることがテストの一番の目的です。
  気付いた問題はすべて報告してください（第 7 節）。
- **キーは手元に残ります。** モデルにアクセスするキー（API キー）はお使いの
  パソコン上のファイルにだけ保存され、見られるのはあなただけです。
  DESMAN のネットワーク、所有者、モデルには送られず、チャット履歴にも残りません。
  ネットワークに送られるのは、キーを識別する短い文字列である
  *フィンガープリント*だけです。そこから元のキーを復元することはできません。
- **ネットワークへの参加は自分で決めます。** **参加** を押すまで（第 5 節）、
  DESMAN が所有者のサーバーに接続することはありません。タスク、チャット、ファイルは
  常にお使いのパソコンに残り、リクエストはキーを追加したモデルの提供元にだけ送られます。
- **ネットワークに参加すると、運営者（サーバーの所有者）に以下が見えます。**
  - あなたのノードの鍵のフィンガープリント、最終接続日時、貸し出したモデルと
    1 日の上限（提供元、モデル、キーのフィンガープリント。キーそのものは送られません）。
  - お使いのパソコンがネットワークのために行った作業とその結果。
  - 送信した問題報告。確認画面に表示された文章がそのまま送られます（第 7 節）。
  - メッセージ機能でのあなたの名前と、誰が誰にいつ送信したか。本文は暗号化され、
    運営者には読めません。**ただし苦情を申し立てると**、対象のメッセージの本文が
    運営者に送られます。
  - 一般のウェブサイトと同じように、接続元の IP アドレス。
- **Windows でコードを実行する。** Docker Desktop をインストールして Linux コンテナモードで起動し、
  `desman sandbox setup --yes` を実行してイメージのダウンロードを許可します。
  コードの実行権限（`shell_execution`）は DESMAN の設定で有効にできます。
  サンドボックスがなくても DESMAN はコードを書けますが、実行にはユーザーの助けを求めます。
  Docker Desktop をインストールするには、セットアップウィザードの Docker セクションを使うか、`desman docker install --yes` を実行してください。
  Windows や macOS で Docker が使えない場合は、`desman sandbox setup --yes` で Python と pytest 用の WebAssembly サンドボックスをセットアップできます。

## 1. インストール

所有者からインストール用のボタンがあるページのリンクが届きます。
インターネット接続が必要です。管理者権限は不要です。

### Windows

1. ページの **Windows** を押すと `install.bat` がダウンロードされます。
   ブラウザーで保存するか聞かれたら「保持」を選んでください。
2. 「ダウンロード」フォルダーを開き、`install.bat` をダブルクリックします。青い画面に
   「Windows によって PC が保護されました」と出たら「詳細情報」→「実行」を押します。
3. 黒いウィンドウが開き、必要なソフト（uv、Python、入っていなければ Git）の
   インストールを許可するか聞かれます。`y` を入力し、Enter キーを押します。
   数分かかります。
4. 完了するとブラウザーで DESMAN のページが開き、デスクトップに **DESMAN** の
   ショートカットができます。次回からはこのショートカットで起動してください。

### Linux

1. ページの **Linux** を押し、表示されたコマンドをコピーします。
2. 端末を開き、Ctrl+Shift+V で貼り付けて Enter キーを押します。
3. Git が入っていない場合は、インストール用のコマンドが表示されます。
   そのコマンドを実行し、手順 2 を繰り返します。
4. 質問には `y` と答えます。完了するとブラウザーが開き、アプリケーションメニューと
   デスクトップに **DESMAN** が表示されます。ショートカットの起動を許可するか
   聞かれたら、許可してください。

詳しくは [install.md](install.md) をご覧ください。

## 2. 初回起動とキー

DESMAN はインターネット上のモデルを使います。モデルを使うには、
プログラム用のパスワードにあたる無料のキーが必要です。初回起動時に設定が自動で開きます。

1. **言語** で「日本語」または使いたい言語を選びます。
2. **キー。** 次のどちらかから始めると簡単です。どちらも無料で、アカウントだけ必要です。
   - **Groq** — https://console.groq.com/keys （ログインし、「Create API
     Key」でキーを作成してコピー）。
   - **Google AI Studio** — https://aistudio.google.com/apikey
     （Google アカウントでログインし、「Create API key」でキーを作成してコピー）。

   設定画面のキー入力欄に貼り付けます。文字が隠れるのは正常です。
   複数の提供元のキーを登録できます。一つのキーが上限に達すると DESMAN は別のキーに
   切り替えます。**チャットにはキーを絶対に貼り付けないでください**。キー入力欄だけを使います。
3. **権限。**
   初期状態ではすべてオフです。テストでは「モデルプロバイダー以外のネットワークを使う」をオンにできます。
   これでエージェントが公開ウェブページを読めるようになります。
   所有者から指示がなければ、ほかの権限はオフのままにしてください。
4. **desman-global** は設定の最後に聞かれます。「今は参加しない」を選び、
   後で参加することもできます（第 5 節）。

無料枠は小さく、変わることがあります。上限に達しても、枠が回復すれば作業は続きます。
通常は 1 分ほどですが、1 日かかることもあります。1 時間以上返答がなければ報告してください
（第 7 節）。

## 3. 使い方

DESMAN の画面はブラウザーに表示されます。

- **左**にチャット一覧があり、下に **設定**、**問題を報告**、**メッセージ** のボタンがあります。
- **中央**はチャット欄です。普段の言葉でやってほしいことを書いてください。
- **右**には **タスク**（作業中の内容）と **モジュール**（動作中のモデル）が表示されます。

簡単な質問にはすぐ答えます。「書いて」「作って」「調べて」など手間のかかるお願いは
*タスク*になります。DESMAN が手順を考え、実行して確認し、結果をチャットで伝えます。
タスクのファイルは専用のフォルダーに保存され、場所も表示されます。

途中で失敗すると、DESMAN がどうするか尋ねます。チャットの下に
**この回答で再試行**、**そのまま承認**、**失敗として記録**
が表示されます。直してほしい点を文章で伝えることもできます。

設定、権限、キーなど DESMAN 自体を変更するときは、別の画面で「はい」を押して初めて
反映されます。心当たりのない確認画面が出たら「いいえ」を押してください。

チャット欄に `/` と入力するとコマンド一覧が出ます。`/help` はヘルプ、`/new` は新しいチャットです。
何かのやり方が分からないときは、DESMAN に普段の言葉で聞いてもかまいません。

## 4. 試してほしいこと

好きなように使ってください。最初は、次のようなことを試せます。

1. 「何ができる？」「設定方法を教えて」など、簡単な質問をします。
2. 文章を頼みます。「土曜の集まりについて近所の人に手紙を書いて」
   「京都への 2 日間の旅行を計画して」など。
3. コードを頼みます。「文章の単語数を数える Python プログラムを書いて」など。
   Linux で「シェルコマンドを実行する」の権限を有効にしていれば、そのプログラムも実行します。
4. 「今度は … を追加して」と頼み、タスクを続けます。
5. タスクの途中で画面を閉じ、ショートカットで開き直します。タスクは続くはずです。
6. 「短く答えて」などと言葉で設定の変更を頼みます。確認画面が開くはずです。
7. ネットワークに参加し（第 5 節）、別の参加者にメッセージを送ります（第 6 節）。

不自然、分かりにくい、遅いと感じたことは覚えておくか、メモしてください。
それも問題として報告できます。

## 5. desman-global ネットワーク

`desman global donate searxng --calls N` で管理下の SearXNG 検索を貸し出せます。ウェブ検索エンジンがなければ `desman global search on|off` で借り入れを切り替えられます。

desman-global は参加者のパソコンをつなぎます。あなたのパソコンは、*貸し出した*
モデルで他の人のタスクの一部を担当できます。大きなタスクではネットワークが空いている
パソコンをまとめてグループにします。自分のタスクが優先され、他の人の作業は
あなたの DESMAN が空いている間だけ行われます。

**参加するには：**

1. **設定** → **desman-global** を開きます。
2. **レジストリ** 欄に所有者から届いたサーバーのアドレスを貼り付けます。`https://` で始まります。
3. **参加** を押すと、あなたのノードのフィンガープリントが表示されます。

**モデルを貸し出すには**（任意）：同じ画面でモデルを選び、**1日の呼び出し数** と
**1日のトークン数** を設定して
**貸し出す** を押します。**取り戻す** で貸し出しを解除できます。今のところ貸し出せるのは
*ローカル*モデル（パソコン上で動く Ollama）だけです。無料のクラウドキーには
他の人のための利用を禁止する条件があるため、貸し出せません。
キーは常に手元に残ります。あなたの DESMAN がモデルを呼び出し、結果だけをネットワークに渡します。

**退出するには：** 同じ画面の **退出** を押します。その時点でネットワークへの送信は止まります。

ネットワークは DESMAN のページを開いている間だけ動作します。
サーバーに接続できないときは DESMAN が単独で動作し、後でもう一度接続します。

## 6. メッセージ

参加者同士でやり取りできます。メッセージは暗号化され、運営者には誰が誰にいつ送ったか
分かりますが、本文は読めません。

1. **名前。** チャットに `/global name あなたの名前`
   と入力します。使えるのはラテン文字の小文字、数字、
   `_`、`-` で、3～32 文字です。この名前は他の参加者にも見えます。
2. **連絡先。** 相手の同意が必要です。`/global contact add 名前`
   で申請します。相手は同じコマンドに
   あなたの名前を入れて承認します。
3. **送信。** `/global send 名前 "メッセージの本文"`
   を使います。本文に空白が入る場合は半角の二重引用符 `"` で囲みます。
   以下のコマンドでも同じです。
4. **閲覧。** 左の **メッセージ** を押すか、`/messages` または `/messages 名前` を使います。
5. **ブロック。** `/global block 名前` を使います。相手には通知されません。`/global unblock 名前`
   で解除できます。
6. **苦情。** `/global complain 名前 "何が起きたか"`
   を使います。特定のメッセージを運営者に見せるには `--message 番号` を追加します。
   番号は閲覧時に表示されます。**そのメッセージの本文は運営者に送られます**。

DESMAN は他の参加者からのメッセージをタスクとして実行しません。
そこに含まれるリンクやファイルから処理が始まることもありません。
完全なアンインストールなどでノードの鍵ファイルを失うと、メッセージも失われます。

## 7. 問題の報告

報告にはネットワークへの接続が必要です（第 5 節）。

1. 左下の **問題を報告** を押します。
2. 何をしたか、どうなると思ったか、実際にどうなったかを書きます。
   例：「手紙を頼んだら、3 ステップ中 2 ステップ目で 20 分止まったままです」。
3. 運営者に送られる**文章そのもの**が別の画面に表示されます。入力した説明と、
   プログラムおよびシステムのバージョンが含まれます。読んでから「はい」を押します。

報告にはキーが入りません。本文にあなたのキーを見つけると、DESMAN は送信を中止します。
チャット、プロフィール、タスクのファイルも送られません。特定のタスクの履歴を
添えるには `/global report "問題の説明" --task 番号`
と入力してください。何が追加されるかは確認画面で分かります。

ネットワークにつながらない、または起動できないため送信できない場合は、
普段の方法で所有者に連絡してください。可能なら画面の画像も添えてください。

## 8. 更新

更新が勝手に入ることはありません。所有者から新版のお知らせが来たらネットワークに
接続し（第 5 節）、`/global update --show` で確認、`/global update --apply 番号`
でインストールします。
DESMAN が変更内容を表示して確認を求めます。インストール後は DESMAN を閉じて開き直します。
「保護されたファイル」の表示が出たら、`/protected approve` と入力して画面で確認すると、
新しいルールが承認されます。前の版に戻すには `/global update --revert` を使います。

## 9. アンインストール

- **Windows：** DESMAN を閉じて Win+R を押し、
  `%LOCALAPPDATA%\DESMAN\app\install\install.bat -Uninstall` を貼り付けて Enter キーを押します。
- **Linux：** DESMAN を閉じ、端末で
  `sh ~/.local/share/desman-app/install/install.sh --uninstall` を実行します。

プログラムが削除されても、再インストールに備えて設定（キーを含む）と履歴は残ります。
すべて消すには Windows では `-Purge`、Linux では `--purge` を追加してください。
DESMAN は何を削除するかを表示して、もう一度確認します。

作成したキーは提供元のウェブサイトで無効化できます（リンクは第 2 節）。
