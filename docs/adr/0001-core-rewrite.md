# ADR 0001 — Переписать ядро, оставить CLI и конфигурацию

- **Статус:** принято
- **Дата:** 2026-10-26
- **Контекст:** аудит из `ROADMAP.md` (дефекты B1–B9)

## Контекст

Первая версия ядра (`core/`, `runtime/`, `review/`, `router/`, коммит `3d10a5e`) имеет дефекты,
которые сидят в самой связке хранилища и координатора: зависания при отказе зависимости,
отсутствие восстановления зависших подзадач, выбор подзадач без учёта зависимостей,
запись файлов вне workspace. Чинить это по месту дороже, чем написать заново с тестами.

## Решения

1. **Ядро пишется заново** небольшими PR по `ROADMAP.md`. Старый код остаётся в истории git
   (`3d10a5e`) как справочник, в дереве его нет.
2. **CLI и конфигурация остаются**: `desman`, `desman config`, `desman help`, мастер настройки
   и `config.json` (`ConfigManager`) в папке проекта, под `.gitignore` и с правами `0600`
   (установленный пакетом DESMAN без папки проекта пишет в `~/.config/desman/config.json`).
   Это единственный источник ключей и настроек; `.env` и `desman setup` удалены. Путь к
   конфигу можно переопределить через `DESMAN_CONFIG_DIR` (используется в тестах).
3. **Синхронный код.** Один процесс, SQLite, вызовы LLM по одному — асинхронность здесь
   только добавляет сложность и сложные для отладки зависания. Параллелизм в Фазе 4 —
   это отдельные процессы-воркеры над одной БД, а не корутины.
4. **Хранилище — stdlib `sqlite3`**, явный SQL и нумерованные миграции. Ключевые операции
   (атомарный claim подзадачи, продление lease) — одиночные `UPDATE … RETURNING`, их проще
   увидеть и проверить в сыром SQL, чем через ORM. Режим WAL + `busy_timeout`.
5. **Pydantic v2** — для всех контрактов: спецификации задач, ответы LLM, вердикты ревьюера,
   конфиг.
6. **HTTP к LLM — `httpx`** напрямую по OpenAI-совместимому протоколу, без SDK `openai`:
   нужен полный контроль над ретраями, классификацией ошибок (400/401 vs 429 vs 5xx)
   и логированием вызовов.
7. **Статусы подзадач — явная state machine** с таблицей допустимых переходов. Checkpoint —
   данные, а не статус.
8. **Python ≥ 3.11**, разработка на 3.12, CI на 3.11–3.13. mypy `--strict`, ruff.

## Последствия

- Минимум зависимостей: `click`, `pydantic`, `httpx`. `sqlalchemy`, `openai`, `tenacity`,
  `anyio`, `rich`, `python-dotenv` убраны; при реальной необходимости возвращаются
  отдельным решением.
- `CLAUDE.md` обновлён под эти соглашения.
- Разрешения из мастера (`permissions` в конфиге) станут *верхней границей* политики
  инструментов (задача 3.2): агент не может получить больше, чем разрешил человек, и не может
  изменить эти значения сам.
