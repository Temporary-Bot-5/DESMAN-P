# DESMAN(P): 테스트 참가자 안내서

테스트에 참여해 주셔서 감사합니다. 이 안내서는 DESMAN 설치 방법, 시험해 볼 기능, 문제 신고 방법을
설명합니다. 먼저 1–3절을 읽고 나머지는 필요할 때 찾아보세요.

## 0. 먼저 읽어 주세요

- **이 프로그램은 시제품입니다.** 갑자기 종료되거나 멈추거나 이상한 답을 내놓을 수 있으며, 끝나지
  않은 작업이 사라질 수 있습니다. 중요한 일이나 다시 할 수 없는 일은 맡기지 마세요. 문제를 찾는
  것이 테스트의 가장 중요한 결과입니다. 발견한 문제는 모두 신고해 주세요(6절).
- **키는 사용자만 보관합니다.** 모델에 접속하는 데 쓰는 API 키는 컴퓨터의 파일에만 저장되며 본인만
  볼 수 있습니다. DESMAN 네트워크나 소유자, 모델에 전달되지 않고 채팅 기록에도 남지 않습니다.
  네트워크에는 키를 구별할 수 있지만 원래 키로 되돌릴 수 없는 짧은 문자열인 *지문*만 전송됩니다.
- **네트워크는 직접 켜야 합니다.** **참여** 버튼을 누르기 전까지(5절) DESMAN은 소유자의 서버에
  접속하지 않습니다. 작업, 채팅, 파일은 항상 컴퓨터에 남고, 요청은 키를 추가한 모델의 공급자에게만
  갑니다.
- **네트워크에 참여하면 운영자(서버 소유자)가 볼 수 있는 정보:**
  - 내 노드의 키 지문, 최근 접속 시각, 빌려준 모델과 일일 할당량(공급자, 모델, 키 지문이며 키
    자체는 제외).
  - 내 컴퓨터가 네트워크를 위해 처리한 작업과 그 결과.
  - 제출한 문제 신고. 확인 창에 표시된 내용 그대로 전송됩니다(6절).
  - 일반 웹사이트와 마찬가지로 접속한 곳의 IP 주소.
- **Windows에서 코드 실행하기.** Docker Desktop을 설치하고 Linux 컨테이너 모드로 실행한 뒤,
  `desman sandbox setup --yes`를 실행해 이미지 다운로드를 승인하세요.
  DESMAN 설정에서 코드 실행 권한(`shell_execution`)을 켤 수 있습니다.
  샌드박스가 없어도 DESMAN은 코드를 작성할 수 있으며, 실행할 때는 도움을 요청합니다.
  Docker Desktop을 설치하려면 설정 마법사의 Docker 섹션을 이용하거나 `desman docker install --yes`를 실행하세요.
  Docker를 사용할 수 없으면 `desman sandbox setup --yes`는 WSL2가 있는 Windows에서 WSL 샌드박스를 설정하고, 그 밖의 경우에는 Python과 pytest용 WebAssembly 샌드박스를 설정합니다.

## 1. 설치

소유자가 설치 버튼이 있는 페이지 링크를 보내 줍니다. 인터넷 연결이 필요하며 관리자 권한은 필요하지
않습니다.

### Windows

1. 페이지에서 **Windows** 버튼을 누르면 `install.bat` 파일이 내려받아집니다. 브라우저에서 파일을
   유지할지 물으면 ‘유지’를 선택하세요.
2. 다운로드 폴더에서 `install.bat` 파일을 두 번 클릭하세요. 파란색 ‘Windows의 PC 보호’ 창이 뜨면
   ‘추가 정보’ → ‘실행’을 누르세요.
3. 검은 창이 열리고 uv, Python, 그리고 필요한 경우 Git을 설치할지 묻습니다. `y`를 입력하고 Enter를
   누르세요. 몇 분 걸립니다.
4. 설치 프로그램은 터미널에서 `desman`을 실행합니다. 바탕 화면의 **DESMAN** 바로 가기도 터미널에서 실행합니다.

### Linux

1. 페이지에서 **Linux** 버튼을 누르고 표시된 명령을 복사하세요.
2. 터미널을 열고 Ctrl+Shift+V로 붙여 넣은 다음 Enter를 누르세요.
3. Git이 없으면 설치 프로그램이 Git 설치 명령을 보여 줍니다. 그 명령을 실행하고 2단계를 다시
   하세요.
4. 질문에 `y`로 답하세요. 설치 프로그램은 터미널에서 `desman`을 실행합니다. 앱 메뉴와 바탕 화면에 **DESMAN**이 나타납니다. 바로 가기 실행을 허용할지
   물으면 허용하세요.

자세한 내용은 [install.md](install.md)를 참고하세요.

## 2. 첫 실행과 키 설정

첫 설정은 터미널에서 진행됩니다. 마지막 질문에서 실험적 브라우저 화면을 선택할 수 있습니다. 나중에 `desman interface terminal` 또는 `desman interface gui`로 변경할 수 있습니다.

DESMAN은 인터넷에 있는 모델을 이용합니다. 모델에 접속하려면 프로그램용 비밀번호에 해당하는 무료
키가 필요합니다. 처음 실행하면 설정 화면이 자동으로 열립니다.

1. **언어**에서 ‘한국어’ 또는 원하는 언어를 선택하세요.
2. **키.** 다음 두 서비스 중 하나로 시작하는 것이 가장 쉽습니다. 둘 다 무료이며 계정만 있으면
   됩니다.
   - **Groq** — https://console.groq.com/keys (로그인하고 ‘Create API Key’를 선택해 키를
     복사하세요).
   - **Google AI Studio** — https://aistudio.google.com/apikey (Google 계정으로 로그인하고 ‘Create
     API key’를 선택해 키를 복사하세요).

   설정 화면의 키 입력란에 붙여 넣으세요. 글자가 가려지는 것은 정상입니다. 여러 공급자의 키를
   추가할 수 있습니다. 한 키의 한도를 다 쓰면 DESMAN은 다른 키로 바꿉니다.
   **채팅 메시지에 키를 붙여 넣지 마세요**. 반드시 키 입력란에만 넣으세요.
3. **권한.** 처음에는 모든 권한이 꺼져 있습니다. 테스트 중에는 ‘모델 공급자 외의 네트워크 사용’을
   켜서 에이전트가 공개 웹페이지를 읽도록 할 수 있습니다. 소유자가 따로 요청하지 않으면 나머지는
   꺼 두세요.
4. **desman-global.** ‘나중에’를 선택하고 이후에 참여해도 됩니다(5절).

무료 한도는 적고 바뀔 수 있습니다. 한도에 도달했다는 메시지가 나오면 한도가 다시 채워질 때 작업이
이어집니다. 보통 1분, 때로는 하루가 걸립니다. 한 시간 넘게 답이 없으면 신고해 주세요(6절).

## 3. 사용 방법

실험적 브라우저 화면의 구성은 다음과 같습니다.

- **왼쪽**에는 채팅 목록이 있고, 아래에 **설정**, **문제 신고**, **메시지** 버튼이 있습니다.
- **가운데**는 채팅입니다. 필요한 것을 평소 쓰는 말로 적으세요.
- **오른쪽**에는 **작업**(지금 하는 일)과 **모듈**(일하는 모델)이 표시됩니다.

간단한 질문에는 바로 답합니다. ‘써 줘’, ‘만들어 줘’, ‘알아봐 줘’ 같은 큰 요청은 *작업*이 됩니다.
DESMAN이 단계를 계획하고 실행하고 확인한 뒤 채팅에서 결과를 알려 줍니다. 작업 파일은 전용 폴더에
저장되며 위치도 알려 줍니다.

어떤 단계에 실패하면 어떻게 할지 묻습니다. 채팅 아래에 **이 답변으로 재시도**, **그대로 수락**,
**실패로 표시** 버튼이 나타납니다. 무엇을 고칠지 말로 알려 줘도 됩니다.

설정, 권한, 키처럼 DESMAN 자체를 바꾸려면 별도 창에서 ‘예’를 눌러야 합니다. 예상하지 못한 창이면
‘아니요’를 누르세요.

채팅 입력란에 `/`를 입력하면 명령 목록이 나옵니다. `/help`은 도움말, `/new`는 새 채팅입니다.
원하는 일을 어떻게 하는지 말로 물어봐도 됩니다.

## 4. 시험해 볼 일

편하게 사용하세요. 처음에는 다음을 해 볼 수 있습니다.

1. ‘무엇을 할 수 있어?’, ‘어떻게 설정해?’처럼 간단히 물어보세요.
2. ‘토요일 모임에 대해 이웃에게 편지 써 줘’, ‘부산으로 이틀 여행을 계획해 줘’ 같은 글쓰기 작업을
   맡겨 보세요.
3. ‘텍스트의 단어 수를 세는 Python 프로그램을 작성해 줘’처럼 코드를 부탁해 보세요. Linux에서
   ‘셸 명령 실행’ 권한을 켜면 DESMAN이 실행도 합니다.
4. ‘이제 …도 추가해 줘’라고 하며 작업을 이어 가세요.
5. 작업 도중 창을 닫고 바로 가기로 다시 여세요. 작업이 계속되어야 합니다.
6. ‘답변을 짧게 해 줘’처럼 평소 말로 설정 변경을 요청하세요. 확인 창이 나와야 합니다.
7. 네트워크에 참여하고(5절) 다른 참가자에게 메시지를 보내세요(6절).

이상하거나 이해하기 어렵거나 느린 부분도 문제입니다. 기억해 두거나 적어 두세요.

## 5. desman-global 네트워크

`desman global donate searxng --calls N`으로 관리형 SearXNG 검색을 빌려줍니다. 자체 웹 검색 엔진이 없으면 `desman global search on|off`로 검색 빌리기를 켜거나 끕니다.

desman-global은 참가자의 컴퓨터를 연결합니다. 내 컴퓨터는 내가 *빌려준* 모델로 다른 사람의 작업
일부를 처리할 수 있습니다. 큰 작업에는 네트워크가 쉬고 있는 컴퓨터를 묶어 그룹을 만듭니다. 내
작업이 항상 우선이며, 내 DESMAN이 쉬는 동안에만 다른 사람의 작업을 처리합니다.

**참여하려면:**

1. **설정** → **desman-global**을 여세요.
2. **레지스트리** 입력란에 소유자가 보내 준 서버 주소를 붙여 넣으세요. 주소는 `https://`로
   시작합니다.
3. **참여** 버튼을 누르면 내 노드의 지문이 나옵니다.

**모델 빌려주기**(선택): 같은 화면에서 모델을 고르고 **일일 호출 수**와 **일일 토큰 수**을 설정한
뒤 **빌려주기**를 누르세요. **회수** 버튼으로 되가져올 수 있습니다. 지금은 내 컴퓨터에서 돌아가는
Ollama 같은 *로컬* 모델만 빌려줄 수 있습니다. 무료 클라우드 키는 약관에 따라 다른 사람을 위한
작업에 쓸 수 없습니다. 키는 내 컴퓨터에 남습니다. 내 DESMAN이 직접 모델을 호출하고 결과만
네트워크에 보냅니다.

**나가려면** 같은 화면에서 **나가기**를 누르세요. 네트워크는 즉시 내 컴퓨터로부터 데이터를 받지
않게 됩니다.

DESMAN 페이지가 열려 있을 때 네트워크 기능이 작동합니다. 서버에 연결할 수 없으면 DESMAN은 혼자
작업을 계속하고 나중에 다시 연결합니다.

## 6. 문제 신고 방법

채팅에서 DESMAN의 문제를 설명하면 확인할 수 있도록 신고 내용을 제안합니다.

신고하려면 네트워크에 연결되어 있어야 합니다(5절).

1. 왼쪽 아래에서 **문제 신고** 버튼을 누르세요.
2. 무엇을 했고, 어떤 결과를 기대했고, 실제로 어떻게 됐는지 써 주세요. 예: ‘편지를 써 달라고 했는데
   3단계 중 2단계에서 20분째 멈춰 있어요.’
3. 창에 운영자에게 전달될 **정확한 내용**이 나옵니다. 작성한 설명과 프로그램 및 시스템 버전이
   포함됩니다. 읽고 ‘예’를 누르세요.

신고에는 키가 포함되지 않습니다. 내용에서 키가 발견되면 DESMAN은 전송하지 않습니다. 채팅, 프로필,
작업 파일도 보내지 않습니다. 특정 작업의 기록을 첨부하려면
`/global report --task 번호 "문제 설명"`을 입력하세요. 확인 창에서 추가될 내용을 볼 수 있습니다.

네트워크에 연결되지 않거나 프로그램이 열리지 않아 신고할 수 없다면 평소 방법으로 소유자에게
연락하고 가능하면 화면 캡처를 첨부하세요.

## 7. 업데이트

업데이트는 자동으로 설치되지 않습니다. 소유자가 새 버전을 알리면 네트워크에 연결하고(5절),
`/global update --show`로 확인한 뒤 `/global update --apply 번호`으로 설치하세요. DESMAN이 변경
내용을 보여 주고 확인을 요청합니다. 설치 후 DESMAN을 닫고 다시 여세요. ‘보호된 파일’ 안내가 나오면
`/protected approve`을 입력하고 창에서 확인해 새 규칙을 승인하세요. 이전 버전으로 돌아가려면
`/global update --revert`를 쓰세요.

## 8. 삭제

- **Windows:** DESMAN을 닫고 Win+R을 누른 뒤
  `%LOCALAPPDATA%\DESMAN\app\install\install.bat -Uninstall`을 붙여 넣고 Enter를 누르세요.
- **Linux:** DESMAN을 닫고 터미널에서
  `sh ~/.local/share/desman-app/install/install.sh --uninstall`을 실행하세요.

터미널에서 `desman uninstall`로 같은 제거 계획을 확인하고 `desman uninstall --yes`로 승인할 수 있습니다. 설정 → 일반 → DESMAN 제거를
사용해도 됩니다.

프로그램이 삭제되어도 다시 설치할 때를 대비해 설정(키 포함)과 기록은 남습니다. 모두 지우려면
Windows에서는 `-Purge`, Linux에서는 `--purge`를 추가하세요. DESMAN이 삭제할 항목을 보여 주고 다시
확인을 요청합니다.

발급받은 키는 공급자 웹사이트에서 폐기할 수 있습니다(링크는 2절).
