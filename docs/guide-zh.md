# DESMAN(P): 测试参与者指南

感谢你参与测试。本指南介绍如何安装 DESMAN、可以试用哪些功能，以及如何报告问题。
可以先看第 1–3 节，其余部分用到时再查阅。

## 0. 请先阅读

- **这是一个原型。** 程序可能崩溃、卡住、给出奇怪的回答，或丢失尚未完成的工作。
  请不要交给它重要的工作，也不要给它无法重做的任务。发现问题是这次测试最重要的成果，
  请把遇到的每个问题都报告给我们（第 7 节）。
- **密钥只由你保管。** 模型访问密钥（API 密钥）只保存在你电脑上的一个文件里，
  只有你能看到。它不会发给 DESMAN 网络、所有者或模型，也不会写入聊天记录。
  网络收到的只有密钥的*指纹*，即一串用来区分不同密钥、却无法还原密钥的短字符。
- **只有你能开启网络。** 在你点击 **加入**（第 5 节）之前，DESMAN 不会联系所有者的服务器。
  你的任务、聊天和文件始终留在你的电脑上。请求只发给你已添加密钥的模型提供商。
- **加入网络后，运营者（服务器所有者）可以看到：**
  - 你的节点，包括节点密钥的指纹、上次连接时间、出借的模型和每日配额
    （提供商、模型及密钥指纹，密钥本身不会发送）；
  - 你的电脑为网络做了什么工作，以及工作结果；
  - 你提交的问题报告，内容与确认窗口中的文字完全一致（第 7 节）；
  - 在消息功能中，你的名字，以及谁在什么时候给谁发了消息。消息经过加密，
    运营者看不到正文，**投诉时例外**。如果你投诉某条消息，运营者会收到那条消息的正文；
  - 和其他网站一样，服务器会看到连接来源的 IP 地址。
- **在 Windows 上运行代码。** 安装 Docker Desktop 并以 Linux 容器模式启动，
  然后运行 `desman sandbox setup --yes` 以授权下载镜像。你可以在 DESMAN 的设置中开启
  运行代码的权限（`shell_execution`）。没有沙箱时，DESMAN 仍可编写代码，并会请你帮忙运行。
  要安装 Docker Desktop，请使用设置向导中的 Docker 部分，或运行 `desman docker install --yes`。

## 1. 安装

所有者会发给你一个带安装按钮的页面链接。你需要联网，无需管理员权限。

### Windows

1. 点击页面上的 **Windows**，下载 `install.bat`。如果浏览器询问是否保留文件，选“保留”。
2. 打开“下载”文件夹，双击 `install.bat`。如果显示蓝色窗口“Windows 已保护你的电脑”，
   点击“更多信息” → “仍要运行”。
3. 黑色窗口打开后，安装程序会询问能否安装所需的软件（uv、Python，以及缺少时安装 Git）。
   输入 `y` 并按回车。安装需要几分钟。
4. 安装完成后，浏览器会打开 DESMAN 页面，桌面会出现 **DESMAN** 快捷方式。
   今后用这个快捷方式启动程序。

### Linux

1. 点击页面上的 **Linux**，复制显示的命令。
2. 打开终端，按 Ctrl+Shift+V 粘贴命令，再按回车。
3. 如果没有安装 Git，安装程序会显示安装 Git 的命令。运行该命令，再重复第 2 步。
4. 遇到提问请输入 `y`。完成后，浏览器会打开，应用程序菜单和桌面上都会出现 **DESMAN**。
   如果桌面提示是否允许启动这个快捷方式，请允许。

更多安装细节见 [install.md](install.md)。

## 2. 首次启动和密钥

DESMAN 通过互联网使用模型。你需要一把免费的密钥，它相当于程序使用的密码。
首次启动时，页面会自动进入设置。

1. 在 **语言** 中选择“简体中文”或你使用的语言。
2. **密钥。** 最方便的是从以下任一服务开始。两者都免费，只需要账号：
   - **Groq** — https://console.groq.com/keys （登录，选择“Create API Key”，复制密钥）。
   - **Google AI Studio** — https://aistudio.google.com/apikey
     （用 Google 账号登录，选择“Create API key”，复制密钥）。

   将密钥粘贴到设置中对应的输入框。字符隐藏是正常的。你可以添加不同提供商的多个密钥。
   一个密钥的额度用完后，DESMAN 会换用另一个。**切勿把密钥粘贴到聊天消息里**，
   只能粘贴到密钥输入框。
3. **权限。** 所有权限默认关闭。测试时可以开启“访问模型提供商以外的网络”，
   这样智能体就能读取公开网页。其余权限请保持关闭，除非所有者另有说明。
4. **desman-global** 是设置中的最后一项。可以选择“暂不加入”，以后再加入（第 5 节）。

免费额度不多，也会变化。如果 DESMAN 提示额度用完，等额度恢复后工作会继续，
通常等一分钟，有时要等一天。如果超过一小时没有回答，请报告（第 7 节）。

## 3. 使用方法

DESMAN 窗口实际上是浏览器里的一个页面：

- **左侧**是聊天列表，底部有 **设置**、**报告问题** 和 **消息**。
- **中间**是聊天区，用平常说话的方式写下你的需求。
- **右侧**是 **任务**（DESMAN 正在做什么）和 **模块**（哪些模型在工作）。

简单问题会得到即时回答。较大的请求（“写一份……”“做一个……”“查清楚……”）
会变成一项*任务*。DESMAN 会规划步骤、逐步执行并检查，最后在聊天中告诉你结果。
每项任务有自己的文件夹，DESMAN 会告诉你文件在哪里。

如果某一步失败了，DESMAN 会问你怎么办。聊天区下方会出现 **使用此回答重试**、**按原样接受** 和
**标记失败**。
你也可以直接说明要改什么。

更改 DESMAN 本身的设置、权限或密钥，需要在单独的窗口里点击“是”。
如果窗口出乎意料地弹出，请点击“否”。

在聊天框里输入 `/` 就能看到命令列表。`/help` 打开帮助，`/new` 开始新聊天。
也可以直接问 DESMAN 怎样做某件事。

## 4. 可以试什么

按你平时的方式使用就好。可以从这些事情开始：

1. 问一个简单的问题，例如“你会做什么？”或“怎么设置你？”。
2. 试试写作任务，例如“写一封信告诉邻居周六要开会”或“安排一次为期两天的成都旅行”。
3. 试试编程任务，例如“用 Python 写一个统计文本词数的程序”。在 Linux 上开启
   “运行 shell 命令”权限后，DESMAN 还会运行这个程序。
4. 继续一项任务，例如“现在再加上……”。
5. 在任务进行到一半时关闭窗口，再用快捷方式打开。任务应该能继续。
6. 用自己的话请求更改设置，例如“回答简短一点”。这时应该出现确认窗口。
7. 加入网络（第 5 节），给另一位参与者发消息（第 6 节）。

把觉得奇怪、难懂或太慢的地方记下来。这些也算问题。

## 5. desman-global 网络

desman-global 把参与者的电脑连在一起。你的电脑可以用你*出借*的模型做别人任务中的一小部分。
遇到大任务，网络会把空闲的电脑组成“集群”。你自己的任务始终优先，
只有当你的 DESMAN 空闲时才会做别人的工作。

**加入网络：**

1. 打开 **设置** → **desman-global**。
2. 把所有者发给你的服务器地址粘贴到 **注册中心** 输入框。地址以 `https://` 开头。
3. 点击 **加入**，页面会显示你的节点指纹。

**向网络出借模型**（可选）：在同一节选中模型，设置 **每日调用次数** 和 **每日令牌数**，再点击
**出借**。
点击 **收回** 可以收回模型。目前只能出借*本地*模型（运行在你电脑上的 Ollama）。
免费云端密钥的使用条款不允许用它为其他人工作，因此无法出借。
你的密钥始终留在电脑上。你的 DESMAN 自己调用模型，只把结果交给网络。

**退出网络：** 点击同一节中的 **退出**。网络会立即停止接收来自你电脑的任何数据。

DESMAN 页面打开时，网络功能才会运行。连不上服务器时，DESMAN 会独立工作，稍后再试。

## 6. 消息

网络参与者可以互发消息。消息经过加密。运营者能看到谁在何时给谁发了消息，
但无法看到正文。

1. **名字。** 在聊天框输入 `/global name 你的名字`。名字会显示给其他参与者。长度为 3–32 个字符，
   只能用小写拉丁字母、数字、`_` 和 `-`。
2. **联系人。** 对方同意后才能互发消息。用 `/global contact add 名字` 发送请求；
   对方用同一条命令填入你的名字即可接受。
3. **发送。** 使用 `/global send 名字 "消息内容"`。如果文字里有空格，请用英文直双引号 `"` 括起来，
   下文的命令也一样。
4. **查看。** 点击左侧的 **消息**，或输入 `/messages`、`/messages 名字`。
5. **屏蔽。** 使用 `/global block 名字`，对方不会收到通知。用 `/global unblock 名字` 解除屏蔽。
6. **投诉。** 使用 `/global complain 名字 "发生了什么"`。如果要让运营者查看某条消息，附加
   `--message 编号`。
   查看消息时会显示编号。**这条消息的正文会发送给运营者**。

DESMAN 不会把其他人发来的消息当成任务执行，里面的链接和文件也不会启动任何操作。
如果丢失节点的密钥文件（例如彻底卸载程序时），消息也会丢失。

## 7. 怎样报告问题

发送报告需要连接网络（第 5 节）。

1. 点击左下角的 **报告问题**。
2. 写清楚你做了什么、期望怎样，以及实际发生了什么。例如“我让它写一封信，
   任务在第 2 步卡了 20 分钟，一共 3 步”。
3. 弹出的窗口会显示将发给运营者的**完整原文**，包括你的描述和程序及系统版本。
   阅读后点击“是”。

报告不会包含密钥。如果 DESMAN 在正文中发现你的密钥，就会取消发送。
聊天记录、个人资料和任务文件也不会发送。如要附上某项任务的记录，请输入
`/global report "问题描述" --task 编号`。确认窗口会显示具体会附上什么。

如果网络连不上或程序打不开，无法提交报告，请按平时的方式联系所有者。
方便的话，请附上截图。

## 8. 更新

更新不会自动安装。所有者通知有新版本后，请先连接网络（第 5 节）。
用 `/global update --show` 查看更新，用 `/global update --apply 编号` 安装。DESMAN
会显示将发生哪些变化，并请你确认。
安装后关闭并重新打开 DESMAN。如果出现“受保护的文件”的提示，请输入
`/protected approve` 并在窗口里确认，以接受新版规则。要退回上一版本，请用
`/global update --revert`。

## 9. 卸载

- **Windows：** 关闭 DESMAN，按 Win+R，粘贴
  `%LOCALAPPDATA%\DESMAN\app\install\install.bat -Uninstall`，再按回车。
- **Linux：** 关闭 DESMAN，在终端运行
  `sh ~/.local/share/desman-app/install/install.sh --uninstall`。

卸载后会保留设置（包括密钥）和历史记录，方便以后重装。要连同密钥和记录全部删除，
请在 Windows 上加 `-Purge`，或在 Linux 上加 `--purge`。DESMAN 会显示将删除的内容，再请你确认。

你可以到各提供商的网站撤销自己创建的密钥，链接见第 2 节。
