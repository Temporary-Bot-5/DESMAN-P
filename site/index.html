DESMAN(P)

A research prototype · Under your supervision

Small agents. Shared work.

A research prototype for a decentralized, fault-tolerant, self-evolving network of small AI agents.

Windows ↓

Paste this command into a terminal. It asks before installing uv; --yes skips the question (see the guide).

(f="$(mktemp)" && trap 'rm -f "$f"' EXIT && curl -fsSL https://raw.githubusercontent.com/Temporary-Bot-5/DESMAN-P/master/install/install.sh -o "$f" && sh "$f")

Windows: save install.bat (use Save link as), then double-click it. On Windows the agents do not run code because there is no sandbox.

  1. Install

    Choose your system. The installer sets up Python and opens the interface.

  2. Add a free key

    Use the setup window to add a free provider’s API key.

  3. Chat

    Describe your task. You approve changes and control permissions.
