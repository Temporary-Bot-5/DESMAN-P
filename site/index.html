Windowsinstall.bat↓

Paste this command into a terminal. It asks before installing uv; --yes skips the question (see the guide).

(f="$(mktemp)" && trap 'rm -f "$f"' EXIT && curl -fsSL https://raw.githubusercontent.com/Temporary-Bot-5/DESMAN-P/master/install/install.sh -o "$f" && sh "$f")

Windows: save install.bat (use Save link as), then double-click it. On Windows the agents do not run code because there is no sandbox.

What stays in your hands

Your keys stay with you

An API key lives only in a file on your computer. It never reaches a model, the chat history or the network.

You confirm every change

Settings, permissions and keys change only after you press “Yes” in a separate window.

Work survives a crash

Tasks are saved step by step. Close the window in the middle of a task and it carries on later.

The network only if you join

desman-global stays off until you join it. Your tasks, chats and files stay on your computer.

This is a prototype. It may crash, hang or lose unfinished work. Don’t trust it with anything important.
